Add five layout primitives: `sl-stack` (flex column — direct children's block margins are zeroed), `sl-content` (prose flow column — children keep their margins and siblings get rhythm via `> * + *`), `sl-wrap` (wrapping horizontal run, children get `min-inline-size: 0`), `sl-grid` (auto-fill minmax columns, `--sl-grid-min` floor at 14rem — or an explicit `sl-grid-cols="1..12"` track count, with `sl-grid--span="2..12|full"` on children for multi-track items), and `sl-sidebar` (wrapping two-zone page section). Spacing is one generic attribute: `sl-gap="xs..5xl"` inherits down the tree so it can be set on an ancestor — the nearest write wins — while per-primitive `--sl-*-gap` slots (`--sl-stack-gap`, `--sl-content-gap`, `--sl-wrap-gap`, `--sl-grid-gap`, `--sl-sidebar-gap`, `--sl-float-gap`, `--sl-bar-gap`) are the non-inheriting escape hatches.

Responsive variants ride the container scale: `sl-grid-cols-lg`, `sl-grid-cols-md`, `sl-grid-cols-sm` restate the track count below 75/60/45rem (narrow overrides wide), and spans clamp to the restated count. The clamp tracks explicit counts only — in auto-fill a span wider than the real tracks can still spawn implicit tracks, so `sl-grid--span="full"` is the safe full row there. `sl-hide-lg/md/sm` hides below its breakpoint on any element and `sl-show-lg/md/sm` mirrors it for content that only exists below the line, so a hide/show pair swaps content across the breakpoint.

Page regions ship too: `sl-bar` is one full-width band for both page edges — a three-column grid with left/dead-center/right zones claimed by `sl-bar--start`/`sl-bar--center`/`sl-bar--end` children (unmarked children auto-fill in source order), `"top"`/`"bottom"` stick to their edge (sticky by default, `sl-bar-fixed` pins to the viewport, bare stays in flow), the matching-side hairline comes free, a fixed bar auto-pads body by `--sl-bar-h`, and `sl-pad` composes for thicker bands; `sl-sidebar` pairs with `sl-sidebar--rail` children (side follows DOM order, wrap driven by the main column's `min-inline-size` — no media query); and `sl-float` is the fixed corner region for notices (six corners as space-separated `<edge> <side>` tokens — `top`/`bottom` × `start`/`center`/`end`, order-free and partial-friendly, width `--sl-float-w` capped to the viewport). `sl-container` takes `"sm"|"md"|"lg"` as its value (bare = `md`). Child parts use double-dash names (`sl-grid--span`, `sl-sidebar--rail`, `sl-bar--start`/`--center`/`--end`, `sl-card--section`, `sl-card--corner`, `sl-notice--action`).

Robustness pass: the layout package stands alone — `border-box` ships on the primitives that measure their own box, `--sl-bg`/`--sl-border` carry fallbacks, and `--sl-pad` can't leak from ancestors into `sl-bar`. Track counts and spans run on self-sealing private vars, so `sl-grid--span` clamps to the active count in every `sl-grid-cols` mode and an outer grid can't leak its count into a nested one. `sl-float` caps its height to the viewport, honors `--sl-float-e` in its width clamp, and clears the home indicator via `env()`; fixed bars and floats go static in `@media print`. The per-primitive gap slots are registered non-inheriting via `@property`, so a bare primitive nested under a `sl-gap`-valued one still reads the inherited gap while inline `--sl-*-gap` overrides stay local (needs Firefox 128+, Safari 16.4+, Chrome 85+). New hooks: `--sl-bar-z`, `--sl-float-z`, `--sl-bar-pad-inline`, `--sl-container-pad`.

BREAKING vs 0.3.x: `sl-container-sm`/`sl-container-md`/`sl-container-lg` are replaced by `sl-container="sm|md|lg"` (bare = `md`); `sl-card-section` → `sl-card--section`; `sl-card-corner` → `sl-card--corner`; `--sl-i-transform`/`--sl-i-shadow` → `--sl-interactive-transform`/`--sl-interactive-shadow`. Layout vocabulary introduced during the 0.4.0 cycle (`sl-toast`, `sl-with-sidebar`, `sl-flow`, `sl-place`, `sl-row`, `sl-collapse`, `sl-cols`, `sl-span`, `sl-fixed`, `sl-static`) is superseded by the names above — if you tracked the branch, treat this release as the canonical API.
