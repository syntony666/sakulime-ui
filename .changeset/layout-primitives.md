Add four layout primitives: `sl-stack` (vertical rhythm — the parent owns spacing and direct children's block margins are zeroed; the `sl-flow` mark switches to prose mode where children keep normal block layout and their own margins, and `sl-cols="2..12"` splits it into balanced text columns with `sl-span` crossing all of them), `sl-row` (wrapping horizontal run), and `sl-grid` (auto-fill minmax columns, `--sl-grid-min` floor at 14rem — or an explicit `sl-cols="1..12"` track count, with `sl-span="2..12"` on children for multi-track items). The attribute value is the gap and takes the full scale (`xs`–`5xl`, bare attribute = `md`) via per-primitive `--sl-*-gap` slots. `sl-row` also takes an opt-in `sl-collapse` modifier that switches it to a stretched vertical stack below the `sm` breakpoint (45rem, the `--sl-container-sm` twin).

Responsive variants ride the container scale: `sl-cols-lg`, `sl-cols-md`, `sl-cols-sm` restate the track count below 75/60/45rem (narrow overrides wide), and spans wider than the active count clamp to a full row. On a grid, bare `sl-collapse` is the `sl-cols-sm="1"` shorthand. `sl-hide-lg/md/sm` is the generic counterpart — `display: none` below its breakpoint on any element — and `sl-show-lg/md/sm` mirrors it for content that only exists below the line, so a hide/show pair swaps content across the breakpoint.

Page regions ship too: `sl-bar` is one full-width band for both page edges — `"top"`/`"bottom"` stick to their edge (sticky by default, `sl-fixed` pins to the viewport, `sl-static` stays in flow), the matching-side hairline comes free, a fixed bar auto-pads body by `--sl-bar-h`, and `sl-pad` composes for thicker bands; `sl-with-sidebar` + `sl-sidebar` rails (side follows source order, wrap driven by the content min-width — no media query); and `sl-toast` (fixed corner region for notices; width `--sl-toast-w` capped to the viewport, value moves the corner across six positions). `sl-container` takes `"sm"|"md"|"lg"` as its value (bare = `md`), replacing the three `sl-container-*` attributes. `sl-place` is the generic placement attribute — `start`/`center`/`end` values pin the inline edge and `top`/`middle`/`bottom` pin the block edge via auto margins, on block, flex, and grid parents alike; two words compose across axes (`sl-place="middle end"` lands right-centre). Bar zone pinning and sidebar order marks layer their structural meaning on the same values; in `sl-row` a `center` child switches the line to three zones (`1fr auto 1fr`) so the marked cell is the true midpoint rather than a margin share. A generic `sl-gap` attribute sets spacing on any gap-reading element — a primitive's own value still wins.

Robustness pass: the layout package now stands alone — `border-box` ships on the primitives that measure their own box, `--sl-bg`/`--sl-border` carry fallbacks, and `--sl-pad` can't leak from ancestors into `sl-bar`. Track counts and spans run on private vars (`--sl-gc`/`--sl-span-n`), so `sl-span` clamps to the active count in every `sl-cols` mode, `sl-span="full"` spans `1/-1` in either mode, and children can't inflate tracks past their share. `sl-toast` completes the corner set (`top-*`/`bottom-*` × `start`/`center`/`end`), caps its height to the viewport, honors `--sl-toast-e` in its width clamp, and clears the home indicator via `env()`; `sl-row` collapse gains `sl-collapse-md`/`sl-collapse-lg`; bars and toasts go static in `@media print`. New hooks: `--sl-bar-z`, `--sl-toast-z`, `--sl-bar-pad-inline`, `--sl-container-pad`.
