頁面區塊

頁面外框的四個區塊：頂列、側欄、頁尾、通知角。標個屬性就定位，內容放什麼都可以。

頂列 sl-bar="top"

預設 sticky，內容滾到頂就停住。要固定在視窗頂部寫 sl-bar="top" sl-fixed。

側欄 sl-with-sidebar

側欄位置看 HTML 順序，主欄窄於下限就整組換行，不用 media query。
