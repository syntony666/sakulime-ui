# AGENTS

Working agreement for coding agents in this repo. Contributor-facing rules live in [CONTRIBUTING.md](./CONTRIBUTING.md); this file covers how agents operate here.

## Protocol

- Plan before implementing non-trivial work; wait for explicit approval.
- Report after each step: files touched, what changed, verification output. Wait for review before continuing — including when a check fails.
- State-changing actions need their own explicit approval: git checkout/merge/rebase/commit/push/reset, dependency installs, deploys.
- Never claim a check passed unless it was actually run and observed.
- Commit messages in English, under 50 words.

## Repo notes

- `npm run build` must precede `npm run release` — publish consumes `dist/` bundles.
- `doc/.storybook/theme.values.ts` is generated by `gen-theme-values.ts` on every storybook start — never edit it.
- Package exports resolve to **source**, not dist (`./index.css` → `src/*.css`) — that's what gives `doc/` live reload. `./package.json` is exported so `createRequire` in `scripts/build.mjs` and `doc/.storybook/` can resolve package roots; keep it exported.
- `@sakulime-ui/shared` is internal-only: private and changesets-ignored. Its vars get inlined into every published bundle at build time.
- All four packages are `fixed` — any changeset bumps them together.
- Merge into `release/x.y.z` and then `master` with `--no-ff` only — no fast-forwards.
- Pushing `master` runs changesets/action → "chore: release" PR → merge publishes to npm (secret: `NPM_TOKEN`). Cloudflare Workers Builds deploys `doc/` independently on `master` pushes — not part of the Action.
- The docs subtree's history lives under `doc/` — don't rewrite those commits when rebasing.
