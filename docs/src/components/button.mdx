## 顏色 `sl-tone`

- `primary`：主題主色（預設值）
- `secondary`：主題副色
- `success`：代表成功
- `warning`：代表警告
- `danger`：代表危險

## 型態 `sl-variant`

- `normal`：整顆填滿（預設值）
- `invert`：只剩框線跟字
- `underline`：只有底線
- `ghost`：沒底沒框，只有字

<Canvas of={ButtonStories.Variants} sourceState="shown" />

## 尺寸 `sl-size`

- `sm`：小
- `md`：一般（預設值）
- `lg`：大

<Canvas of={ButtonStories.Sizes} sourceState="shown" />

## 圓角 `sl-radius`

- `none`：直角
- `sm`：微圓
- `md`：一般圓角（預設值）
- `lg`：很圓
- `full`：膠囊形，全圓到底
