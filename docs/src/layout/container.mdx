# Container 容器

把內容限制在一個寬度裡，置中，左右各留 16px。掛在哪個元素都可以，`class` 留給你。

<Canvas of={ContainerStories.Container} sourceState="shown" />
<Controls of={ContainerStories.Container} />

## 屬性

- `sl-container-sm`：720px
- `sl-container-md`：960px
- `sl-container-lg`：1200px

三個真的容器放在 1200px 寬的頁面裡。`lg` 貼滿兩邊，其他兩個照上限置中。手機上三個看起來一樣。看不完可以左右捲動，或按 `S` 收起側邊欄。

<Canvas of={ContainerStories.ContainerWidths} sourceState="shown" />

要更改數值可以覆寫 `--sl-container-sm/md/lg`。
