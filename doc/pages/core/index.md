# 元件

不需要排版工具時，可以只載入元件，裡面也會有主題包：

```bash
npm install @sakulime-ui/core
```

```ts
import "@sakulime-ui/core/index.min.css";
```

## CDN

把下面這行放進 `<head>...</head>`：

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@sakulime-ui/core/dist/index.min.css" />
```
