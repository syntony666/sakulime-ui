# 排版工具

只需要排版工具時：

```bash
npm install @sakulime-ui/layout
```

```ts
import "@sakulime-ui/layout/index.min.css";
```

## CDN

把下面這行放進 `<head>...</head>`：

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@sakulime-ui/layout/dist/index.min.css" />
```
