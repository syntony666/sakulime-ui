# Card 卡片

帶邊框的內容容器 — surface 底色、細框線、圓角、內距。可以只放文字，也能組合貼邊圖片與標記。

<Canvas of={CardStories.Card} sourceState="shown" />
<Controls of={CardStories.Card} />

## 貼邊圖片 `sl-card-media`

包一層 `sl-card-media` 讓圖片貼到卡片邊緣，圓角會自動裁切：

```html
<div sl-card>
  <div sl-card-media><img src="..." /></div>
  <div><strong>標題</strong><p>內容</p></div>
</div>
```

<Canvas of={CardStories.WithMedia} sourceState="shown" />

## 內距 `sl-pad`

- `none`：不內縮
- `sm`：小
- `md`：一般（預設值）
- `lg`：大

<Canvas of={CardStories.Pads} sourceState="shown" />

## 圓角 `sl-radius`

- `none`：直角
- `sm`：微圓
- `md`：一般圓角（預設值）
- `lg`：很圓
- `full`：全圓到底

<Canvas of={CardStories.Radius} sourceState="shown" />

## 型態 `sl-variant`

- `horizontal`：圖片在左、內容在右
- `hollow`：虛線描邊，常用於上傳或空白狀態

<Canvas of={CardStories.Variants} sourceState="shown" />

## 標記 `sl-indicate` + `sl-tone`

在卡片某個邊緣加一條強調色，顏色吃 `sl-tone`（預設 primary）：

- `top` / `bottom` / `start` / `end`

## 角落標記 `sl-card-corner`

在卡片頂端角落放一個小標記，適合時間、狀態、數字這類補充資訊。屬性值用空格分隔，類型和位置可以自由組合。顏色跟著 `sl-tone` 走（預設 primary）：

```html
<div sl-card>
  <span sl-card-corner="end text-sm">100ms</span>
  ...
</div>
```

<Canvas of={CardStories.Corner} sourceState="shown" />
<Controls of={CardStories.Corner} include={["sl-tone", "sl-radius"]} />

寫在卡片上整張統一，寫在標記上只改那一個：

```html
<div sl-card sl-tone="success">
  <span sl-card-corner="end indicator" sl-tone="danger"></span>
</div>
```

類型：

- `text-sm`：小字標籤（省略類型時的預設）
- `text-xs`：更小的字級
- `indicator`：純色圓點，裡面放 `svg` 或 `img` 就變圖示（圓點不會出現；SVG 寫 `currentColor` 會跟著 `sl-tone` 的顏色）

位置：

- `end`：右上（預設值）
- `start`：左上

```html
<span sl-card-corner="start text-xs">6ms</span>
<span sl-card-corner="end indicator"></span>
<span sl-card-corner="end indicator">
  <svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2"><!-- icon --></svg>
</span>
```
